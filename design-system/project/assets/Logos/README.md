# Logos

- `trueround-lockup.svg`: mark + wordmark for light grounds. Ink `#0f1214`, check `#b8891a`.
- `trueround-lockup-dark.svg`: mark + wordmark for dark grounds. Ink `#eeeeea`, check `#e2b53e`.
- `trueround-mark.svg` / `trueround-mark-dark.svg`: the three-round ring with the gold check. App icon, favicon, avatar fallback.
- `trueround-wordmark.svg` / `trueround-wordmark-dark.svg`: wordmark alone, single ink.

The check is always gold. Everything else is the ink of the ground it sits on.
