# Logos

Vector masters rebuilt from the TrueRound brand sheet. The wordmark and tagline are outlined Montserrat, so no font is needed. Files ending `-light` are for white grounds; the rest are for black.

- **Lockups:** `trueround-logo-horizontal.svg` (primary) and `trueround-logo-stacked.svg`. Emblem, wordmark and the tagline TRAIN • TRACK • IMPROVE.
- **Emblem:** `trueround-emblem.svg`. A ring broken into four rounds; the gold one becomes the check.
- **Single colour:** `trueround-emblem-mono-white.svg` and `trueround-emblem-mono-gray.svg`, for embossing, watermarks and one-colour print.
- **Wordmark:** `trueround-wordmark.svg`. TRUE in white (black on light), ROUND in gold.
- **App icons:** `trueround-app-icon.svg` (black, primary), `-gold`, `-white`, `-outline` (black with a gold edge). All 1024 x 1024 with a 224 corner radius.

The check and ROUND are always brand gold `#E6B800`, except in the monochrome files.
