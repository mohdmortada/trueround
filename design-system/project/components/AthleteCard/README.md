# AthleteCard

The fighter card: the face of the growth loop. It shows only verified facts, so it is worth sharing.

- `photo` replaces the initials with a portrait (any image URL, cropped to a circle). Leave it out and the initials show.
- `corner` adds the corner stripe when the card appears on a bout page.
- `verified` shows the gold badge once every bout in the record has a signed sheet.
- For athletes under 18, show first name and last initial, gym and level only: no photo, no record, no weight, no nation.
