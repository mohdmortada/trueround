# Badge

A short status beside a name, a skill or a result. The status decides the colour and the icon; the words are yours.

- `verified` (gold, check) means an authorised person signed it off: a coach, an official, an event doctor.
- `pending` (amber, clock) means waiting on someone. Say who: "Awaiting coach".
- `cleared` (green, shield) is medical clearance or eligibility.
- `suspended` (stop, bar) is a medical or disciplinary hold. Always pair it with an end date nearby.
- `neutral` for counts and plain labels.
- Never use a badge for decoration or for a corner colour; that is `CornerTag`.
