# Icon

Line icons on a 24px grid, 2px stroke, square caps and mitred joins to match the squared-off wordmark. Colour follows the text colour.

Names: `check`, `clock`, `shield`, `ban`, `home`, `ladder`, `card`, `play`, `calendar`, `user`, `lock`, `scale`, `whistle`, `share`, `settings`, `camera`, `back`.

- Pass `label` when the icon stands alone and means something; otherwise it is hidden from screen readers.
- No emoji anywhere in the product.
